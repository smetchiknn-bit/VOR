# Генератор ВОР (Ведомость объёмов работ)

Streamlit-приложение для автоматической привязки кодов **КЕР** и **ТМЦ**
к позициям спецификации с тройной детализацией
(Спецификация → КЕР → ТМЦ) и трассировкой по колонке «Строка».

В репозитории также есть веб-версия (React + Vite, `npm install && npm run dev`) —
тот же алгоритм выполняется в браузере и отдаёт идентичный ВОР.xlsx.
В репозитории также есть веб-версия (React + Vite, `npm run dev`) —
тот же алгоритм выполняется прямо в браузере и отдаёт идентичный ВОР.xlsx.

## Возможности

- Подбор Код КЕР по ключевым словам наименования (19 правил), база КЕР
  фильтруется «Навигатором КЕР»: Л2 Код / Л3 Код (по умолчанию 2.8 / 2.8.3).
- Подбор Код ТМЦ: первое слово — ключ, оценка по пересечению слов,
  +10 за артикул, −5 за чужую категорию («труб», «светильник»).
- Тройная детализация: «Спецификация» (оба кода) → «КЕР» (без Код ТМЦ) →
  «ТМЦ» (без Код КЕР).
- Строки-заголовки 1/2 уровня сохраняются — иерархия не теряется.
- «№ п/п» — текст с ведущими нулями ('001, '002 …).
- **ВОР.xlsx**: листы «ВОР» (11 колонок), «Статистика», «Не найдено».
- Подбор Код ТМЦ: первое слово наименования — ключ поиска, оценка по
  пересечению слов, +10 за совпадение артикула, −5 за чужую категорию
  («труб», «светильник»).
- Тройная детализация: строка «Спецификация» (оба кода), строка «КЕР»
  (без Код ТМЦ), строка «ТМЦ» (без Код КЕР).
- Строки-заголовки 1/2 уровня (без «Кол-ва») сохраняются — иерархия не теряется,
  в колонке ТА фиксируется «Строка-заголовок (уровень 1/2), иерархия сохранена».
- Колонка «№ п/п»: уникальные системы нумеруются по порядку первого появления,
  значение текстовое с ведущими нулями ('001, '002, …) — Excel не превращает
  номера в числа.
- Итог: **ВОР.xlsx** с листами «ВОР» (11 колонок), «Статистика», «Не найдено».

## Требования

- Python 3.10+

## Установка и запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется по адресу http://localhost:8501.
Приложение откроется в браузере по адресу http://localhost:8501.

## Использование

1. Загрузите три файла (все обязательные):
   - **Спецификация.xlsx** — Файл, Лист, Система, Этаж, Наименование, Артикул,
     Производитель, ЕИ, Кол-во, Масса, Примечания, Строка;
   - **База КЕР.xlsx** — ИД_КЕР, Наименование_КЕР, ЕдИзм КЕР, Иерархия, Л1–Л5, ФЕР;
   - **База ТМЦ.xlsx** — ИД ТМЦ фск, Наименование ТМЦ фск, ЕдИзм ТМЦ, КСР, Бренд, ФСБЦ.
2. Введите **Л2 Код** (2.8) и **Л3 Код** (2.8.3). Пустые поля = значения по умолчанию.
3. Нажмите **«Сформировать ВОР»** и скачайте файл.

## Замена Промпт.txt (для посвящённых)

Промпт встроен в код как константа `PROMPT_TXT`, явной кнопки загрузки нет.
Заменить его можно двумя скрытыми способами:

1. **Файл рядом с app.py** — положите `Промпт.txt` в папку приложения:
   при запуске он прочитается автоматически (приоритет у файла).
2. **Скрытая кнопка «· · ·»** внизу сайдбара (почти невидима, проявляется при
   наведении) — служебная зона: прикрепление нового Промпт.txt для сессии и
   возврат к встроенному. В веб-версии дополнительно работает пятикратный клик
   по «ВОР» в шапке.

Какой промпт действовал — фиксируется в строке «Промпт.txt»
на листе «Статистика» готового ВОР.xlsx.

## Примечания

- Фасонные изделия отдельный Код КЕР не получают (учтены в расценке на воздуховоды).
- Расход ТМЦ равен Кол-во (ресурсная часть КЕР недоступна).
- Числовые колонки — числа (`pd.to_numeric(errors="coerce")`); в русской локали
  Excel десятичный разделитель — запятая.
- Позиции без кодов не удаляются — лист «Не найдено» с причиной.
   - **Спецификация.xlsx** — колонки: Файл, Лист, Система, Этаж, Наименование,
     Артикул, Производитель, ЕИ, Кол-во, Масса, Примечания, Строка;
   - **База КЕР.xlsx** — колонки: ИД_КЕР, Наименование_КЕР, ЕдИзм КЕР,
     Иерархия, Л1–Л5 Код/Наименование, ФЕР;
   - **База ТМЦ.xlsx** — колонки: ИД ТМЦ фск, Наименование ТМЦ фск,
     ЕдИзм ТМЦ, КСР код Группы, Бренд, ФСБЦ и др.
2. В блоке «Навигатор КЕР» введите **Л2 Код** (например, 2.8) и
   **Л3 Код** (например, 2.8.3). Пустые поля = значения по умолчанию.
3. Нажмите **«Сформировать ВОР»** — обработка идёт с прогресс-баром.
4. Скачайте **ВОР.xlsx** кнопкой под результатами.

## Структура выходного файла (11 колонок)

| № | Колонка | Источник | Тип |
|---|---------|----------|-----|
| 1 | № п/п | расчётный (номер системы) | текст, '001… |
| 2 | Система | Спецификация | текст |
| 3 | Строка | Спецификация — ключ трассировки | текст |
| 4 | Этаж | Спецификация | текст |
| 5 | Наименование | Спецификация / КЕР / ТМЦ | текст |
| 6 | ЕИ | Спецификация / КЕР / ТМЦ | текст |
| 7 | Кол-во | Спецификация | число |
| 8 | Код КЕР | ИД_КЕР из базы КЕР | число |
| 9 | Код ТМЦ | ИД ТМЦ фск из базы ТМЦ | число |
| 10 | Расход ТМЦ | = Кол-во (ресурсная часть недоступна) | число |
| 11 | ТА | источник строки | Спецификация / КЕР / ТМЦ |

## Примечания

- Файл «Промпт.txt» встроен в код приложения как константа `PROMPT_TXT`
  и читается автоматически — загружать его не нужно (кнопки загрузки нет).
- Фасонные изделия (отводы, переходы, тройники, врезки, крестовины, утки,
  заглушки) отдельный Код КЕР не получают — их монтаж учтён в комплексной
  расценке на прокладку воздуховодов.
- Позиции без подобранного кода не удаляются: они остаются в ВОР с пустыми
  идентификаторами и попадают на лист «Не найдено» с указанием причины.
- Числовые колонки записываются числами (`pd.to_numeric(errors="coerce")`);
  в русской локали Excel десятичный разделитель отображается запятой,
  формат ячеек «Кол-во» и «Расход ТМЦ» — `0.00`.
